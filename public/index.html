Jonah Frame

An always-on web application running on a repurposed touchscreen photo frame. A deterministic schedule engine evaluates recurring routines and date-specific overrides, then supplies the current and upcoming activities to the display. A separate module handles environmental data. Sunset can change the sky independently of the bedtime indicator, and ferry motion requires a fresh position report.

The scene uses a static backdrop and separate sprites for moving objects. Reflections that belong to the ferry move with the ferry sprite. The renderer updates only the parts of the interface whose state changed, keeping active touch targets in place while the clock updates.

The touchscreen uses a read-only session. A separate parent interface manages routines, calendar events, and photos. The calculator and letter board hold input only for the current interaction.

Crateflip

An archived music software prototype. The initial design explored beat discovery modeled on digging through records. A later iteration narrowed the public page to one featured track and a set of links per artist, with previous tracks retained in an archive.

PostgreSQL stored profile and track metadata, while audio files used a separate storage interface. That interface supported local files during development and S3-compatible object storage for deployment. The prototype is offline.
